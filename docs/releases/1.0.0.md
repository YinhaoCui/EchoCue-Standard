# EchoCue Standard 1.0.0

- Windows x64 installer with Start-menu integration, optional desktop shortcut and Windows uninstall entry.
- Bundled Python, dependencies and local transcription models; per-user installation with separate persistent data.
- Classic Glass and Midnight Studio interfaces, live transcription, multiple answer providers, reusable prompt scenarios, meeting assistance and in-page shortcut settings.
- Background transparency reaches interface controls while keeping text readable; window and panel resizing have regression coverage.

No personal credentials, configuration or conversation records are included. See the README and user guide for setup.
