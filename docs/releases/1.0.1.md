# EchoCue 1.0.1

- Integrated light and Black Gold Workbench with answer tabs and organized settings.
- Inline model diagnostics, image preview, and separate caption model selection.
- Progressive bilingual captions, improved segment batching, and cleaner reading labels while preserving source metadata.
- Improved window resizing and listening focus handling.
- Removed the retired standalone design prototype and screenshot-only browser test. Behavioral tests remain for Classic and both Workbench palettes.

Windows x64 installer and portable archive include Python, dependencies, and local transcription models. Each download has a SHA-256 checksum. Personal settings, credentials, conversation records, and temporary files are excluded.

Live provider responses, real-audio recognition quality, and third-party screen-sharing behavior are not established by automated regression tests. Installers are unsigned.
