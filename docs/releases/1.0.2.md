# EchoCue 1.0.2

## English

- Built-in DeepL, Google and Microsoft caption translation works without installing DLX or supplying API keys. Google Cloud Translation remains a separate official, metered option.
- Revisable draft translations appear while speech continues, with finalized captions taking priority and bounded batching waits.
- Declarative English sentences such as “This is the current implementation” no longer trigger question-only generation merely because they contain “is”.
- Changing captions or appearance no longer discards an otherwise matching speculative answer. Changes to the question, instructions, credentials, selected model or generation behavior still require a new answer.
- Ask from editable text and capture the monitor under the pointer. Original transcripts remain intact.

The three built-in translation interfaces are unofficial and require internet access; rate limits and interface changes may affect availability. A rate-limited service is paused instead of immediately retried. Reported latency measurements exclude audio recognition and actual desktop rendering.

Choose your edition's installer EXE or portable ZIP, together with its SHA-256 file. Personal settings, credentials and conversations are excluded. Standard retains its existing feature boundary.

## 中文

- 新增内置 DeepL、谷歌和微软字幕翻译，无需安装 DLX 或填写 API Key；Google Cloud 官方计费接口作为独立选项保留。
- 讲话时显示可修订的暂译，定稿优先处理，并限制合句等待。
- 修复英文陈述句仅因包含 is、are 等词就误触发疑问句预生成或自动回答。
- 修改字幕或界面设置时复用有效预生成；问题、要求、凭证、所选模型或生成行为变化时仍重新生成。
- 支持编辑文字问题和截取鼠标所在显示器，完整保留原始转录。

内置免 Key 翻译使用非官方在线接口，仍可能限流或失效。测速不包含语音识别及实际窗口绘制。发布包不含个人资料、凭证或会话；Standard 保持原有功能边界。
