# EchoCue 1.0.3

## 中文

- 核对 Windows 实际置顶层级并在焦点样式变化后同步，避免窗口库状态与系统层级不一致。

- 修复滚动设置页后，延迟到达的滚动事件误关菜单、导致键盘选择失效的问题。

- 修复未开启置顶时，监听窗口无法正常切到前台的问题。
- 修复取消置顶后，后台刷新仍重复抬高窗口、压住其他窗口的问题。置顶阅读时保留不抢焦点的交互，进入文字输入时恢复键盘焦点。
- 移除独立 DLX 服务和 Google Cloud Translation 付费接口及其设置；保留内置免 Key 的 DeepL、谷歌和微软翻译。
- 旧 DLX 选择迁移为内置 DeepL；旧 Google Cloud 选择迁移为内置谷歌翻译。旧服务令牌和 Cloud Key 不再读取或保存。
- 标准版等待原生窗口就绪后再初始化焦点和置顶同步，避免启动时同步线程退出。

请选择对应版本的安装包 EXE 或便携 ZIP；SHA-256 文件可用于校验下载。发布包不包含个人设置、凭证或会话。内置翻译使用非官方在线接口，仍可能限流或失效。

## English

- Synchronize the Windows topmost band after focus-style changes instead of relying only on the window library's cached state.

- Keep keyboard dropdown selection working when a completed focus scroll delivers a delayed event after the menu opens.

- Restore normal foreground switching when the listening window is not pinned.
- Stop background state updates from repeatedly raising an unpinned window. Preserve non-activating controls while reading a pinned window and restore focus for text editing.
- Remove the independent DLX service and the metered Google Cloud Translation option and settings. Keep built-in, key-free DeepL, Google and Microsoft translation.
- Migrate previous DLX and Google Cloud selections to their matching built-in translators. Stop reading or saving obsolete service credentials.
- Wait for the Standard native window to be ready before initializing focus and pin synchronization.

Choose the installer EXE or portable ZIP for your edition and its SHA-256 file. Personal settings, credentials and conversations are excluded. Built-in translators use unofficial online interfaces and remain subject to rate limits and availability changes.
