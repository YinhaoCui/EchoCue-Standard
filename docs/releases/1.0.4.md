# EchoCue 1.0.4

## 中文

- 实时字幕草稿和流式回答更快显示：从后台产生到页面显示的延迟，中位数由约 80 毫秒降至约 30 毫秒，最长由约 150 毫秒降至约 50 毫秒。本地转录的解码线程数经实测保持 4 线程不变。
- 模型列表统一整理：每个模型只列一次；同一系列内思考档位固定按 low、medium、high、xhigh 排列，新版本在前。Claude Code 的别名不再与其对应的完整模型 ID 重复出现，已选的别名仍然有效。
- 新增本机诊断日志 `data/logs/ai-listener.log`（1 MB 滚动，保留 3 份）。写入前会把 API Key 替换为 `[KEY]`，日志不会上传。
- 预热、增量上下文、预测生成、回答时限和输出上限改用与界面语言无关的代码保存；旧设置在加载时自动转换。不支持降级：升级后再用 1.0.3 或更早版本打开同一份设置，需要重新选择这几项，否则回答可能失败。
- 回答、字幕翻译和测速改用同一个平台调用入口；音频采集组件改为开始采集时再加载。

请选择对应版本的安装包 EXE 或便携 ZIP；SHA-256 文件可用于校验下载。发布包不包含个人设置、凭证或会话。内置翻译使用非官方在线接口，仍可能限流或失效。

## English

- Show live transcript drafts and streamed answers sooner: the delay from a worker event to the page drops from about 80 ms to about 30 ms at the median, and from about 150 ms to about 50 ms at most. Local transcription keeps 4 decoder threads, which measured fastest.
- Tidy every model list: each model appears once; within a family, effort variants run low, medium, high, xhigh and the newest version comes first. Claude Code aliases no longer appear beside the model ID they resolve to; a saved alias keeps working.
- Add a local diagnostic log at `data/logs/ai-listener.log` (rotated at 1 MB, three backups). API keys are replaced with `[KEY]` before writing, and the log is never uploaded.
- Store warm-up, incremental context, speculation, time-limit and output-limit options as language-neutral codes; older settings are converted when loaded. Downgrading is not supported: if 1.0.3 or earlier opens the same settings afterwards, re-select these options or answers may fail.
- Route answers, caption translation and the speed test through one provider entry point; load audio capture components only when capture starts.

Choose the installer EXE or portable ZIP for your edition and its SHA-256 file. Personal settings, credentials and conversations are excluded. Built-in translators use unofficial online interfaces and remain subject to rate limits and availability changes.
