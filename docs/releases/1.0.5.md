# EchoCue 1.0.5

## 中文

- 绑定快捷键时提示冲突：与本软件其他功能相同，或已被其他程序占用，输入框旁会立即说明。保存后仍无法注册的快捷键，会标在对应的那一项上。
- 录入快捷键时，本软件暂时不响应自己的快捷键，所以可以直接按下已经在用的组合来重新分配。离开输入框后恢复。

## English

- Report shortcut conflicts while binding: a field says at once when its shortcut matches another action or is already held by another program. A saved shortcut that could not be registered is marked on its own field.
- While a shortcut field has focus the app does not respond to its own shortcuts, so a combination already in use can be pressed to reassign it. They return when the field loses focus.
